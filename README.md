\# Course Recommendation Expert System



\## Project Description



The Course Recommendation Expert System is an AI-based application that recommends a suitable course based on the user's area of interest, current skill level, and career goal.



The system uses predefined IF-THEN rules to make recommendations.



\## AI Technique



Rule-Based Expert System



\## Technologies Used



\- Python

\- Streamlit

\- IF-THEN Rules



\## How the System Works



1\. User enters their area of interest.

2\. User selects their current skill level.

3\. User selects their career goal.

4\. The Expert System compares the inputs with predefined rules.

5\. The matching rule produces a suitable course recommendation.



\## Main Features



\- Simple and user-friendly interface

\- Rule-based AI decision making

\- Course recommendation based on user inputs

\- Explanation for the recommended course

\- Easy to use and understand



\## Example



\### Input



\- Area of Interest: Programming

\- Skill Level: Beginner

\- Career Goal: Software Developer



\### Output



Recommended Course: Python Programming
